# Ritmo

App personal de hábitos: ejercicio desde cero, alimentación consciente y registro de ánimo, con un pingüino multicolor que crece contigo.

- Funciona sin conexión e instalable en el celular (PWA).
- Los datos se guardan solo en el dispositivo (localStorage). Usa **Progreso → Copia de seguridad** para respaldarlos.

Ábrela en: https://hpaez71.github.io/ritmo/
